ホーチミンのグループ旅行に：屋上BBQのある貸切一軒家

ホテルで部屋を3つ取って、毎晩どの部屋に集まるか決める代わりに、一軒家をまるごと。眠るのはそれぞれの部屋で、楽しむのはみんなで。

予約・お問い合わせ

寝るのは別々、過ごすのは一緒に

3つの寝室すべてに専用バスルームとエアコンがあり、気兼ねなく過ごせます。マスターベッドルームは約55㎡、180×200cmベッド、55インチ4Kテレビ、バルコニー付き。ベッドルーム2と3は160×200cmベッドとスマートテレビ、ベッドルーム3は窓がなく朝寝坊に向いています。

エンタメルームの夜

カラオケ

マイクをご用意しています。デュエットで喉を慣らし、ソファに審査員を座らせて歌合戦を。スマートフォンで録画して思い出に残すのもおすすめです。曲や言語はお使いのアプリによって異なります。

PS5 (PlayStation 5)と映画

壁に設置されたPS5 (PlayStation 5)とコントローラー2台、PlayStation Plus。喉を休めたいときはゲーム大会、その後は天井の4Kプロジェクターで映画を一本。

ルーフトップでBBQ

スーパーや市場で食材を買って、屋上のBBQグリルで。ラタンのアウトドアソファとテーブル、夜に灯るストリングライトとソーラーライト。川の向こうの1区のスカイラインを眺めながら乾杯を。

出張・研修チームにも

メッシュWi-Fi（最大1Gbit/s）が3フロアすべてに届きます。午前は前室のデスクで資料をまとめ、夜はチーム全員でルーフトップで食事。

到着と滞在

暗証番号式ドアロックでセルフチェックイン、外門は鍵で。大人数で荷物が多いときは、ご予約時に空港送迎をご依頼ください。洗濯機はご自由にお使いいただけます。

お部屋ごとの詳細

カラオケ・エンタメルーム

カラオケ用マイク、PS5 (PlayStation 5)とPlayStation Plus、天井設置の4Kプロジェクターとスクリーン、大型4Kテレビ。ホーチミン7区の一棟貸しの貸切エンタメルーム。

リビング

ホーチミン7区の一棟貸しの約40㎡のリビング。大型L字ソファ、75インチ4KテレビとNetflix、エアコン、ほかのバスルームと同じ設備のゲスト用トイレ。

キッチン・ダイニング

コンロ、オーブン、炊飯器、エアフライヤー、トースター、約540Lの冷蔵庫と長いダイニングテーブル。洗濯機も使える、ホーチミン7区の一棟貸しのキッチン。

マスターベッドルーム

ホーチミン7区の一棟貸しのマスターベッドルーム。約55㎡、180×200cmベッド、55インチ4Kテレビ、専用バルコニーとバスルーム、ワイヤレス充電付きドレッサー。

ベッドルーム2

ホーチミン7区の一棟貸しのベッドルーム2。160×200cmベッド、スマートテレビ、専用バスルーム、エアコン、カーテン付きの窓、タオルのあるワードローブ。前室から入るお部屋。

ベッドルーム3

窓がなく日中も暗く静かなベッドルーム3。160×200cmベッド、スマートテレビ、専用バスルーム、エアコン、ミラー扉のワードローブ。時差調整やお昼寝に。

バスルーム

ホーチミンの一棟貸しは全寝室に専用バスルーム。黒のシャワー、丸い鏡、壁掛けドライヤー、歯ブラシセット。リビングには同じ設備のゲスト用トイレもあります。

前室・ワークスペース

ベッドルーム2・3に続く前室の窓辺のデスク、メッシュチェア、デスクライト。ドレッサーコーナー、靴箱のある玄関、御影石の階段、最大1Gbit/sのWi-Fi。

屋外・川沿い

川沿いにあるホーチミン7区の一軒家。白い手すりとオーニングのテラスから、川と1区のスカイラインを望めます。

ルーフトップテラス

約56〜60㎡のルーフトップテラス。BBQグリル、ラタンのアウトドアソファ、テーブル、熱帯植物、ソーラーライトとストリングライト、川と1区のスカイラインの眺め。
