無料のホーチミン旅行ガイドアプリ

ASCONガイドは、ホーチミンの地元のおすすめとスポットをまとめた無料のウェブアプリです。スマートフォンのブラウザですぐに開け、パスワードもインストールも不要です。

ホーチミンの宿泊先

家族やグループ旅行なら、ASCON LIVINGは専用バス付き寝室3室、カラオケ、ルーフトップBBQのあるホーチミンの一軒家貸切です。セルフチェックイン、空港送迎はご希望に応じて手配。 空き日程を見る →

旅行ガイドアプリを開く

アプリの中身

スマートフォンで撮影した実際のアプリ画面です。

地元のおすすめとスポット

スポットはグルメ、カフェ・デザート、バー・ナイトライフ、子ども・家族、観光・文化、アクティビティ、リラックス、ショッピング、日帰り旅行、実用情報・緊急などのカテゴリーに分かれています。地図で家の周辺スポットを確認し、ルートをタップすると道案内が開きます。

アプリはホーム画面に追加できます。滞在のアイデアはホーチミン旅行ガイドでもご紹介しています。
