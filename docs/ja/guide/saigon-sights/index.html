歩いて回る旧い中心

大聖堂、中央郵便局、歌劇場は一つの塊として見れば足ります。建物のあいだが近く、そのあいだの歩道が見物の半分です。郵便局は今も働くホールのようで、高い天井と壁の地図があります。前の広場は、暑さが上がる前に立ち止まる場所として優れています。並木と学生と絵はがきが、同じ歩道を使っています。

市庁舎はそのすぐそばで、歩道から見るだけで十分です。余裕が一周だけなら、この一角が合います。日陰とカフェがあるので、行進のように歩かなくてよいのです。重い博物館は、室内にいる気になってからに回してください。

博物館と宮殿

統一会館は、応接の間と地下の状況室、そのあいだの庭が続いています。階段ごとに写真を撮るより、部屋をいくつか読む時間があるときに行ってください。戦争証跡博物館はもっと重い場所です。背景を知りたい大人の場所であり、幼い同行者がいちばん厳しい展示を見るかどうかは、入る前に決めた方がよいでしょう。

美術の博物館は少し離れた旧い建物の中にあり、より静かです。陶磁器や漆、現代の絵が、出入りできる部屋に並びます。どれも単独で一日を要求しません。二カ所と、そのあいだの長い食事が、午前から午後までの形になります。

寺院と静かな路地

香の濃い寺院は、像が多く、噂より小さいことがあります。香と、池の亀と、人の密度が、短い訪問を長く残します。肩と膝は覆い、祈る人をよけ、中庭を舞台にしない。それだけで十分です。

ほかの寺院は、ごく普通の通り、家と仕事場のあいだにあります。その混ざり方が見ものです。龍の屋根の隣に修理の店と学校の門があります。戸が開き、案内が静かなら、静かに見ればよいのです。儀式の最中なら、端に立ってください。

川が風景の一部になるとき

サイゴン川は、橋の上で確認する背景ではありません。岸を少し歩き、はしけを見て、対岸に塔がどう立っているかを見れば足ります。船の話は川のページに譲ります。陸では、向きが目的です。水がどちらへ流れるかが分かると、残りの地図が読めます。

日が傾くころが、いちばんやさしい時間です。暑さが抜け、空が仕事をします。有料の展望台は要りません。公共の歩道と、冷たい一杯と、急がない眺めが、その活動のすべてです。

一日の分け方

外の一周と、室内の一周を組にしてください。暑さが弱いときに中心部、日が高いときに博物館、そのあと寺院か川。計画がほとんどない日を一日残してください。サイゴンには、朝の食卓で作った計画よりよい路地がたくさんあります。

歩ける靴と、水と、軽い鞄が要ります。家は戻り先です。寝室と居間の冷房、もう一度出る前に果物とコーヒーを用意できる台所、街が十分になったときの屋上。その三つが、見どころの日を支えます。

この文章がわざと省いたこと

順位もなく、空いているという約束もありません。予定は変わり、臨時の休館もあります。とくに祝日の前は前日に確認し、閉まった戸は、その界隈を歩くきっかけにしてください。

市場とコーヒーと、街の外の一日には、それぞれページがあります。上の場所は最初の滞在に足り、気に入った道を知る二度目に、もっとよくなります。

最初は地図のピンだけが見えます。一度歩くと、ピンとピンのあいだの歩道が記憶に残ります。その歩道をもう一度歩くことが、見どころの旅行の中身です。新しい場所は少なくてよいのです。よかった日陰を繰り返す方が、点検表よりサイゴンらしい滞在になります。

家と街を分ける

見どころの日は、家で水を一杯飲み、外で一つ二つを見て、家に戻って終わる形がよいのです。寝室ごとに冷房があり、居間にも冷房があるので、昼に横になることは行程の失敗ではありません。台所で果物を洗い、コーヒーメーカーで次の外出を用意できます。

屋上は、川と街の輪郭が見える私的な終わりです。昼に聖堂前で見た空を、夕方にテラスからもう一度見ると、街が一枚につながります。船に乗らなかった日も、川は家の風景として残ります。バーベキューとスモーカーは、その夕方を外で食べたいときの道具です。

同行が複数なら、同じ見どころに無理に揃えなくてよいのです。一人は博物館、一人は郵便局前のカフェ、夕方に同じ玄関へ戻れば足ります。家は一棟まるごと一行のものですから、ロビーで落ち合う必要はありません。玄関のキーパッドと外門の鍵を共有していれば、帰宅の仕方は単純です。靴は一日歩けるものを選び、鞄は軽くしてください。聖堂と博物館と寺院を一日に詰めると、どれも残りません。二つだけでもサイゴンは十分に大きく、翌日に同じ道を逆から歩くと別の街に見えます。
