コースを日の種類にする

自由な旅行が詰まる地点は、情報が足りないからではなく、一日に多すぎる種類を入れるからです。一日には一種類だけ置いてください。聖堂と博物館と市場と遊覧を同じ日付に束ねると、どれも残さないまま玄関に着きます。

短い滞在なら二種類だけ選んでもサイゴンです。長い滞在なら同じ種類を違う光で繰り返してもよいのです。表の枠を埋めることが目的ではありません。明日もその街を歩きたいなら、コースは成功です。

歩きの日

旧い中心は、聖堂、郵便局、市庁舎の前、歌劇場の周りを一塊として歩く日です。日陰とカフェが途中にあるので、行進になりません。岸まで足が残っていれば水を見て、なければ家へ戻ってください。川は別の日の主題であり得ます。

同じ道を逆からもう一度歩く日を一つ置いてもよいのです。初日は道を探し、二日目は日陰を探します。その違いが、自分で組む旅行の中身です。靴は一日歩けるものを選び、鞄は軽くしてください。

室内の日

統一会館か美術の博物館、あるいは戦争証跡博物館のうち一つを選んでください。二つ以上を同じ日に入れなくてもよいのです。展示が重い場所は同行と先に範囲を決め、途中の椅子が見えたら座ってください。室内の日は、暑さを避ける日でもあります。

室内の日は、午後を家へつなぐのに向いています。居間の大きい画面や短い昼寝が、次の展示を無理に足すことよりコースらしいのです。冷房のある家が博物館の次の部屋だと思えば、行程は寛大になります。

市場と台所の日

市場は見物で終えず、台所へつないでください。果物、コーヒー、香草。家に戻って洗い、冷蔵庫へ入れることがその日の後半です。ベンタインだけでもよく、近所の市場だけでもよいのです。両方を同じ午前に終える規則はありません。

この日は夕方を外で新しく探さなくてもよいのです。約540リットルの冷蔵庫とオーブン、電子レンジ、食器を洗う機械が卓のあとを担います。コーヒーメーカーは翌日の朝を先に楽にします。市場の文章が店の態度をさらに書いています。

川か、街の外か

川の日は岸を歩くか遊覧か、どちらか一つを選んでください。両方すると水が課題になります。光のよい遅い午後が楽で、雨ならテラスに替えても川は家の風景に残ります。屋上は約56平方メートルです。

街の外の日は、メコンデルタかクチトンネルのどちらかです。同じ日の二つの外出ではありません。その前日と翌日は家の日として空ける方が、コース全体は崩れません。日帰りの文章が、それぞれの性格を分けて書いています。

家の日

家の日は空欄ではありません。洗濯機を回し、屋上で川を見て、ゲーム機やプロジェクターで午後を過ごし、夕方にバーベキューをしてもよいのです。歌いたければ家の装置で足ります。街へ出なかった日が、次の歩きを生かします。

同行の速度が違うなら、家の日に無理に合わせないでください。一人は昼寝、一人は近くのコーヒー。鍵とキーパッドが同じなら、夕方に同じ食卓です。三つの階があるので、眠りと音が一室に集まりません。

表を畳む仕方

紙に六つの枠を描いて順を書いても、前の夜に二つの枠を消してよいのです。にわか雨、足の疲れ、ただの気分。どれも正当な修正です。消した枠は失敗ではなく、次の訪問か屋上です。

初めて来る週には、歩き、室内、市場で足ります。川と街の外と家の日は、足が慣れてから入れてください。自分で組む旅行とは、ピンが多いことではなく、ピンを抜ける勇気です。

コース同士のリンクだけを辿らないでください。見どころ、市場、川、天気の文章は各日の参考であり、このページはその参考をどの順で開くかを決めます。一日に文章を三本読む必要はありません。

最終日の午前は、新しいコースを開かない方がよいのです。チェックアウトは12:00です。荷物と鍵と外門を整え、コーヒー一杯で自分のコースの終わりとして足ります。見なかった路地は街が保管します。空いた枠が台所や屋上なら、その旅行は既に家を知っている旅行です。
