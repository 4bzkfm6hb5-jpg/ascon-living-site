ホーチミンの宿泊先

家族やグループ旅行なら、ASCON LIVINGは専用バス付き寝室3室、カラオケ、ルーフトップBBQのあるホーチミンの一軒家貸切です。セルフチェックイン、空港送迎はご希望に応じて手配。 空き日程を見る →

空室を確認

川がしていること

岸から見るのは、写真のためだけの水路ではなく、働く水路です。貨物船、観光の甲板、ときどき小さい船が同じ水を使います。対岸は何年もかけて高くなり、輪郭は風景の一部であり、特定の塔一つより光によって変わります。

歩道を少し歩くことが、いちばん単純な盤面です。風と規模、水がどちらへ下るかの感触が来ます。船を予約する前に、この歩みをしてください。陸で水を既に知っていれば、遊覧はよりよく読めます。

遊覧が見せるもの

訪問者の船の多くは、中心の桟橋から出て大きい水路を一周します。港の機械、家の船、橋、旧い倉庫と新しい塔の対比が過ぎていきます。昼の遊覧は川の仕事に近く、遅い遊覧は水の上の光と、灯る街に近いものです。

説明は船ごとに違います。港の話をする船、音楽を流す船、冷たい一杯を渡して手すりに立たせておく船があります。見たいなら静かな船を、一緒の夕方を望むなら活気のある船を選んでください。どちらでも核心は甲板の見せ物ではなく、過ぎていく岸です。

勧めに押されず選ぶ

桟橋、船の種類、何が含まれるかを、お金を払う前に言ってくれる店と決めてください。小さい船の短い一周と、決まった食事のある大きい甲板は感じが違います。食事が要らなければ言い、踊りより座りたいなら座って見える船を選んでください。

既に疲れている日は避けてください。桟橋までの道は混むことがあり、乗船には待ちがあります。肌が日焼けしやすいなら、街が暑く感じても薄い上着を持ってください。水の上の風は、道で見ていたより強いのです。桟橋と甲板のあいだを動くときは、鞄を閉じてください。

天気と光と楽さ

晴れた遅い午後が、楽な選択です。雨の多い月にはにわか雨が来て去り、多くの船は待つか一周を短くします。それは失敗した遊覧ではありません。雲の下の川も川であり、強い日光がなければ街は違って見えます。

空が一日中降り続くなら、船は延ばし、別の日に岸を歩いてください。豪雨の中で出て受け取れる賞はありません。天気のページが二つの季節をもう少し説明し、どの一週も予測できるとは装いません。

降りたあと

降りると中心部はすぐそこにあります。コーヒー、水辺の短い歩き、家へまっすぐの車。どれもよい終わりです。同じ夕方に博物館を重ねないでください。遊覧がその行程の出来事であるべきです。

家の屋上は川と街の輪郭を見ます。甲板とは違う角度で、静かで、出たくない夜にもあります。ある日は船、ある日はテラス。それだけで川の滞在は完成します。屋上は約56平方メートルです。

デルタは別の水

メコンデルタは、この一周を長く伸ばしたものではありません。果樹園と狭い水路と村のある、街の外の一日です。それを望むなら日帰りページを見て、サイゴン川は街の水として残してください。

一つの滞在に両方は可能です。同じ日であってはなりません。街の川は夕方か軽い午後であり、デルタはまる一日とその次の静かな朝を要求します。家をあいだに置けば、両方とも残ります。遊覧を理解した印は写真の数ではなく、降りたあと急がないことです。

川と屋上

遊覧をしない日も、川は家の風景です。屋上テラスからは川と輪郭が見え、バーベキューとスモーカーがあるので、船を降りた翌日はテラスで夕方を食べても川は続きます。

同行が船に弱い、あるいは日が負担なら、無理に乗船しなくてよいのです。岸の歩道と家の屋上だけでも、水に会った日になります。子どもは手すりのある甲板より、テラスの椅子の方が楽なことが多いのです。選択は体裁のためではありません。

長くいれば、川をいくつもの光で見ることになります。晴れた午後、にわか雨の直後、灯のついた夜。同じ屋上でその三つが可能です。遊覧はそのうちの一日で足り、残りは家が代わります。

船の予約を急がないでください。先に歩き、光がよいときに決めればよいのです。サイゴン川は去りません。明日も同じ向きに流れます。その流れを陸で覚えてから甲板に立てば、一周は初めての川ではなく、既に知っている水の確認になります。
