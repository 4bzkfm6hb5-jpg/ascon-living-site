ホーチミンの宿泊先

家族やグループ旅行なら、ASCON LIVINGは専用バス付き寝室3室、カラオケ、ルーフトップBBQのあるホーチミンの一軒家貸切です。セルフチェックイン、空港送迎はご希望に応じて手配。 空き日程を見る →

空室を確認

ASCONガイドアプリ

無料のアプリで、パスワードは不要です。スマートフォンのブラウザで開くため、アプリストアからのインストールは不要です。ホーム画面に追加することもできます。

便利なポイント

各スポットに家からの距離が表示され、「ルート」ボタンで玄関からの道順を確認できます。地図で周辺のスポットを一覧でき、無理のない一日の計画が立てられます。

カテゴリーこんな方に
グルメTop10（家の近く）すべての方、毎日
カフェ・デザートご夫婦、午後のひと休み
キッズ・ファミリー家族旅行
バー・ナイトライフご友人同士
観光・文化、日帰り旅行はじめての方
実用・緊急情報到着、移動、SOS

旅行ガイドアプリを開く

子連れのホーチミン

暑さと交通事情を考えると、午前中に出かけて午後は家で休む計画がおすすめです。アプリの「キッズ・ファミリー」にお出かけ先をまとめています。雨の日は家のエンタメルームで、プロジェクターの映画やカラオケ、PS5 (PlayStation 5)を。

空港から宿まで

タンソンニャット空港からは、ご予約時に依頼できる空港送迎がいちばん楽です。配車アプリやタクシーもあります。アプリの「運転手に見せるカード」には住所がベトナム語で書かれています。到着後は暗証番号式ドアロックでセルフチェックイン、外門は鍵で。

旅のスタイル別の使い方

ご友人同士

グルメとナイトライフのカテゴリーで夜の予定を決め、帰ってからはルーフトップBBQやカラオケで。

ご夫婦

静かなカフェや夕日の見える場所を探して、最後はルーフトップで夜景を。

長期滞在・ワーケーション

最大1Gbit/sのWi-Fiと前室のデスクがあり、仕事の合間のお出かけも計画しやすくなります。
