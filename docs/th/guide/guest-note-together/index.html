ไซง่อนกับครอบครัวหรือกลุ่มเพื่อน

โฮจิมินห์เหมาะกับครอบครัวและกลุ่ม ถ้าวันนั้นแบ่งเป็นจุดกลางแจ้งหนึ่งจุดและจุดในร่มหนึ่งจุด.

จองและติดต่อ

เมื่อไปกับเด็ก

  • สวนสัตว์และสวนพฤกษศาสตร์ไซง่อนเป็นสวนสาธารณะเก่าของเมือง มีทางเดินร่มไม้.
  • หุ่นกระบอกน้ำดูในอาคาร และติดตามได้โดยไม่ต้องมีบทพูดมาก.
  • ตลาดมีหลังคาคับคั่ง จับมือเด็กใกล้ถนนและระหว่างแผง.
  • กลางวันมักร้อน เช้าและบ่ายแก่เหมาะกับข้างนอก กลางวันเหมาะกับพิพิธภัณฑ์ ร้านกาแฟ หรือการพัก.
  • ดื่มน้ำขวดหรือน้ำที่กรองแล้ว.
  • ที่วัดและโบสถ์ควรแต่งกายสุภาพ ที่วัดมักถอดรองเท้า.

เมื่อไปเป็นกลุ่ม

กลุ่มสั่งอาหารจานเล็กหลายจานที่แผง หรือหลายที่ร้านเฝอหรือข้าวแตกได้ ถนนคนเดินเหงียนเว้และลานหน้าโรงละครเป็นจุดนัดตอนเย็นที่หาไม่ยาก เลือกพิพิธภัณฑ์หนึ่งแห่งหรือพระราชวังเพื่ออยู่ด้วยกัน และเหลือเวลาที่ไม่ได้จัดตาราง แทนการยัดทุกจุดในวันเดียว.

หมายเหตุสำหรับทุกคน

  • รถจักรยานยนต์หนาแน่น ข้ามไปกับคนอื่น ด้วยจังหวะสม่ำเสมอ.
  • แผงเล็กมักรับเงินสด บางแห่งมีคิวอาร์โค้ดสำหรับโอนเงิน.
  • ราวเดือนพฤษภาคมถึงพฤศจิกายน ควรมีรายชื่อที่ในร่มติดมือ.

หน้าอื่นบนเว็บไซต์นี้

เมื่อไปกับครอบครัวหรือกลุ่ม ดูคู่มือเที่ยวไซง่อน และคู่มือสถานที่สำหรับผู้เข้าพัก. บ้านถูกแนะนำไว้ที่หน้าแรก.

หากต้องการพักในโฮจิมินห์ หน้าจองและติดต่ออธิบายวิธีจองบ้านหลังนี้. จองและติดต่อ

  • อาหารริมทางในไซง่อน
  • แอปคู่มือเที่ยวโฮจิมินห์ฟรี
  • เที่ยวโฮจิมินห์: คู่มือท้องถิ่นสำหรับแขก ASCON
  • ที่พักโฮจิมินห์แบบบ้านทั้งหลัง สำหรับครอบครัวและกลุ่มเพื่อน
