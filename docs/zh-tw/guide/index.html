西貢美食

熱騰騰的河粉、酥脆的越南法國麵包、碎米飯配烤肉、加煉乳的越式冰咖啡。App整理了第七郡周邊和全市的店，不會只踩到觀光客餐廳。

自己下廚

想在家吃也可以，廚房設備齊全，社區市場就買得到食材。

景點

第一郡的法式殖民建築、傳統市場、博物館，每個地點都在地圖上。給計程車司機看，或輸入叫車App就能出發。

帶小孩

「親子」分類有適合小朋友的活動，雨天備案也有。

行程範例

早上逛市場，吃App推薦的路邊早餐。中午去博物館或在第一郡散步。最熱的時候回家在客廳沙發休息。傍晚頂樓烤肉，最後在娛樂室唱KTV收尾。

烤肉之後

還想出門續攤？「酒吧與夜生活」裡有幾個選擇。
