整栋民宿的客厅：约40㎡，L形沙发和75英寸4K电视

早上端着咖啡下楼的地方，晚上大家最后都会聚到的地方。约40㎡客厅里，有坐得下全组人的L形沙发和75英寸4K电视。

预订与联系

客厅设施一览

项目内容
面积约40㎡
沙发大型L形沙发，白色/奶油色仿皮，橄榄绿和米色靠垫
电视75英寸4K电视，壁挂，Netflix
柜子低矮的深灰色长电视柜
茶几深色玻璃台面
空调壁挂式
窗落地玻璃门，深灰色窗帘
客用卫生间在客厅区域，与其他卫浴配置相同

全组都坐得下的L形沙发

奶油色L形沙发，所有人一起坐也能伸开腿。橄榄绿和米色靠垫、红色毯子，给灰白空间添了点暖意。

早上

孩子在沙发上看动画，大人喝咖啡商量今天去哪。

晚上

出门回来往沙发上一靠，聊聊各自今天吃了什么、去了哪。

75英寸4K电视和Netflix

电视挂在黑色竖纹墙板上，两侧各有一株高大的热带植物。75英寸4K，坐在沙发哪个位置都看得清。Netflix 可否使用取决于当时的有效账户。

光线与氛围

落地玻璃门引进室外的绿色，深灰色窗帘可以调节阳光。天花板暖色灯带、彩色装饰画、挂钟、地球仪和飞机模型，灰、白、灰米色加黑色点缀，安静现代。

客用卫生间和空调

客用卫生间

客厅区域有一间客用卫生间，配置与其他卫浴相同。白天孩子和访客不用跑去卧室的卫浴。

空调

壁挂空调，正午再热客厅也凉快。

无线网络

三层都有 Mesh 无线网络（最高1Gbit/s）。在沙发上回几封邮件、开个视频会议都行；要长时间办公，可以去前厅的办公桌。

与其他空间的连接

客厅连着厨房和长餐桌。唱K和 PS5 (PlayStation 5) 去娱乐室，看日落和天际线上屋顶。

常见问题

客厅多大？

约40㎡，有大型L形沙发、75英寸4K电视、茶几和空调。

客厅有卫生间吗？

有，一间与其他卫浴配置相同的客用卫生间。

能在客厅办公吗？

可以，网速最高1Gbit/s，前厅还有办公桌。
