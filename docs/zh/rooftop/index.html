胡志明屋顶烧烤：看河景和第一郡天际线的独享露台

约56–60㎡的屋顶是 ASCON LIVING 最受欢迎的地方。烧烤炉上烤着肉，看河对岸第一郡的灯光亮起，吃一顿晚饭。

屋顶设施一览

项目内容
面积约56–60㎡
烧烤黑色桶形烧烤炉兼烟熏炉，带侧边置物台
休闲区深色藤编户外沙发，七个奶油色坐垫，奶油色软凳
用餐深色餐桌和藤编座椅
绿植长花槽里的热带植物
灯光太阳能灯、顶棚下的串灯
顶棚部分有遮阳篷
视野河景和第一郡天际线
栏杆白色金属栏杆

烧烤炉

白色栏杆旁的黑色桶形烧烤炉和侧边置物台。超市的肉和蔬菜、市场的海鲜都能烤。食材可以先放进厨房约540升冰箱。

藤编休闲区

深色藤编户外沙发配七个奶油色坐垫和软凳。饭后换个位置接着聊。

餐桌

深色餐桌和藤编座椅，遮阳篷下有灯，晚饭坐得舒服。

河景和天际线

从屋顶望出去，河对岸就是第一郡天际线。傍晚天色变幻，夜里楼宇灯光映在河面。

夜晚的屋顶

顶棚下的串灯和太阳能灯亮起，氛围马上不一样。这里是住宅区，夜深后请轻声交谈。

与整栋房子的连接

菜从厨房端上来，饭后去娱乐室。和主卧阳台一样，是感受户外空气的地方。
