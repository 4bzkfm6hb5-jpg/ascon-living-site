# ASCON LIVING – English texts: where they go

Market Researcher writes; the builder only pastes texts into `content/en.json` in the repo `4bzkfm6hb5-jpg/ascon-living-site`.
Put one file per page in this folder (e.g. `house.md`), using the page IDs and section headings below.

## Rules (enforced at build / by Website Ops)
- Title ≤ 60 characters (the text " | ASCON LIVING" counts), meta description ≤ 160 (imprint 120–160). One main keyword per page in the title + H1; other keywords go in body text only.
- Never write: pool, parking, max guest count, PS5, '500+ games', brand names Hisense/Optoma/FPT/LG, halal/Muslim, 'walking distance' to Phú Mỹ Hưng, 'certified' fire safety. Bedroom 3: say neutrally that it has no window (interior room, quiet and dark).
- Use only confirmed facts (see facts sheet 17 Oct 2026: 3 floors + rooftop, over 250 m², 3 bedrooms 180×200 / 160×200 / 160×200 cm, 3 en-suite bathrooms + guest WC, living room approx. 40 m², rooftop approx. 56–60 m², fridge approx. 540 l, fibre up to 1 Gbit/s down / 300 Mbit/s up, approx. 12 min by Grab to the centre, traffic-dependent).
- 'river view' only on photos where the river is actually visible (marked RIVER below).
- Booking links: Airbnb, Trip.com, WhatsApp and Zalo only.

## What the page format supports
- Per page: `title`, `description`, `h1`, `lead` (1–2 sentences).
- Per section: `h2`, any number of paragraphs, optional bullet list, optional sub-blocks (`h3` + paragraphs) for long body text, optional note.
- Per photo: an alt text (one short sentence describing what is visible, with a keyword where natural) and optionally a separate caption (shown below the photo). If you give only one sentence it is used for both.
